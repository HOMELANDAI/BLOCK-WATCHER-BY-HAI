# BLOCK WATCH by HAI — Development Roadmap

## Phase 0 — Definition

- Finalize naming: BLOCK WATCH by HAI vs public-facing BLOCK WATCHER terminology.
- Establish data/privacy principles.
- Define pilot intersection boundaries.
- Select initial businesses.
- Validate camera placement permissions.
- Define baseline metrics.

## Phase 1 — Analytics MVP

Goal: prove that the street can be measured reliably.

Build:

- Camera ingestion
- Vehicle/pedestrian/scooter detection
- Directional counts
- Time-series aggregation
- Node health
- Basic operator dashboard
- Supabase schema
- Recorded-video simulator

Exit criteria:

- Repeatable accuracy benchmark
- Stable hourly aggregates
- Documented privacy/retention policy

## Phase 2 — Broadcast MVP

Goal: prove that analytics can become entertainment.

Build:

- Twitch broadcast package
- NPC host v1
- Peak Hour Predictor
- Chat/poll integration
- Clip markers
- Daily and weekly recap templates

Exit criteria:

- Returning viewer cohort
- Measurable chat participation
- Repeatable 30–60 minute show format

## Phase 3 — Sponsor MVP

Goal: prove local commercial demand.

Build:

- Business profiles
- Campaigns
- Creative library
- Placement scheduler
- One or two trigger types
- Verification log
- Sponsor dashboard
- QR/redemption tracking

Exit criteria:

- 3–10 paying pilot sponsors
- Verified delivery reporting
- At least one documented case study

## Phase 4 — Maestro Interactive Layer

- Interactive overlays
- Rewards/badges
- Viewer actions
- Sponsor offers
- Leaderboards
- Premium programming

## Phase 5 — Micro-Ad Lab

- Brand intake
- Asset management
- Prompt templates
- Storyboards
- NPC creative
- Approval workflow
- Multi-format export
- Campaign deployment

## Phase 6 — Community Vitality

- Metric definitions
- Public methodology
- Community project registry
- Allocation tracking
- Before/after reporting

## Phase 7 — Digital Twin

- 3D district
- Live node states
- Flow visualization
- Sponsor/AR zones
- Infrastructure layers
- Historical playback

## Phase 8 — Second Geography

Deploy a contrasting location such as Hackensack Main Street to test portability.

## Phase 9 — HAI Verified District

Standardize:

- Node kit
- Deployment checklist
- Privacy framework
- Sponsor model
- NPC localization
- Analytics schema
- Community reporting
- Partner onboarding

## Priority Rule

Do not build the full futuristic interface before proving the data, audience, and sponsor loops. The visual command center is the destination; the MVP must validate the underlying economics and behavior first.
